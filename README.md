# 🔍 TipSearch

**TipSearch** is a simple Python project for retrieving information about an IP address.
It allows you to quickly get basic data such as country, city, ISP, and other network-related details.

---

## 🚀 Features

* 🌍 Detect country and city
* 🏢 Get ISP (Internet Service Provider) information
* ⚡ Fast API-based lookup
* 🖥️ Lightweight and easy to use
